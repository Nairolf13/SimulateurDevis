# ToitureDevis

Application React pour estimer le prix d'une toiture, avec Tailwind CSS et envoi automatique du devis par email via EmailJS.

## Fonctionnalités principales
- Formulaire : surface, type de projet, accès, nom, email/téléphone
- Estimation dynamique du prix selon la formule fournie
- Récapitulatif clair après soumission
- Envoi automatique des infos via EmailJS
- Design épuré, responsive, boutons arrondis, couleurs sobres

## Démarrage

```bash
npm install
npm run dev
```

## Personnalisation EmailJS
Ajoutez vos identifiants EmailJS (clé publique, service ID, template ID) dans le code source.

## Stack
- React (Vite)
- Tailwind CSS
- emailjs-com
